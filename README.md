### 📂 Proyectos destacados

#### 1. 🛴 Urban Scooter – Testing integral (Web, Mobile y API)

Proyecto enfocado en la validación de una aplicación de alquiler de scooters eléctricos, donde se realizaron pruebas completas en **web, mobile y API**, cubriendo funcionalidades clave del sistema.

🔍 **Actividades realizadas:**

**🌐 Aplicación Web:**
- Creación de checklist para validar los requisitos de la pantalla **"Estado del pedido"**
- Diseño de casos de prueba para la pantalla **"Hacer pedido"** (validación de campos)
- Ejecución de pruebas en múltiples navegadores: **Google Chrome y Opera**
- Validación funcional basada en checklist y datos de prueba
- Reporte y seguimiento de errores en Jira

**📱 Aplicación Mobile (App para repartidores):**
- Uso de emulador Android mediante Android Studio para ejecución de pruebas
- Validación del flujo de usuario:
  - Inicio de sesión de repartidores
  - Visualización de pedidos disponibles
  - Selección y gestión de pedidos
- Diseño de casos de prueba para:
  - Notificaciones
  - Comportamiento sin conexión a internet
- Ejecución de pruebas funcionales enfocadas en la experiencia del repartidor

**🔌 Pruebas de API:**
- Creación y validación de checklist para el backend
- Pruebas de endpoints:
  - Gestión de repartidores
  - Consulta de pedidos
  - Cancelación de pedidos

---

📊 **Resultados:**
- 🐞 5 bugs detectados en funcionalidades de estado del pedido (Web)
- 🐞 11 bugs relacionados con validación de datos (Web)
- 🐞 3 bugs en notificaciones (Mobile)
- 🐞 1 bug en eliminación de pedidos (API)

---

🛠️ **Herramientas utilizadas:**
- Jira (gestión de bugs)
- Navegadores: Chrome, Opera
- Postman (API testing)
- Android Studio (Emulador Mobile)

---

🎯 **Valor aportado:**
Este proyecto permitió aplicar pruebas en múltiples plataformas, detectar errores críticos y asegurar la calidad del sistema desde una perspectiva integral, enfocada en la experiencia del usuario y la prevención de fallos.
